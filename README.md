- **HTML/CSS** — semantic markup, responsive layouts, Flexbox/Grid

- **React** — components, hooks, state management, routing
- **Angular** — components, services, routing, forms

### Backend

- **Django** — models, views, serializers, DRF
- **Databases** — PostgreSQL, SQLite, Supabase
- **Authentication** — JWT, OAuth 2.0, session-based
